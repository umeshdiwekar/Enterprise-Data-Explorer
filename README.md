# Enterprise Data Explorer

A fast CSV explorer for `indore.csv`. The browser never receives the full dataset for browsing; it asks the API for the current page only, while the database handles filtering, sorting, counting, and search.

You can also replace the dataset from the browser with the CSV uploader in the header. Uploaded CSVs are validated against the required header, imported in small batches, and then the table refreshes automatically.

## Vercel + Supabase Deployment

Use this path for the free production-style deployment:

1. Create a Supabase project.
2. Open the Supabase SQL editor and run [supabase/schema.sql](supabase/schema.sql).
3. In Vercel, add these environment variables:
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
4. Redeploy the Vercel project.

The deployed API routes live in `api/`. CSV import is chunked in the browser to avoid sending one large 50 MB request to Vercel.

Keep `SUPABASE_SERVICE_ROLE_KEY` only in Vercel environment variables. Do not expose it in frontend JavaScript.

## Local Development

The original local fallback still works with SQLite:

```bash
npm run import-data
npm run dev
```

Open `http://127.0.0.1:3000`.

That local Python server is useful for offline testing, but Vercel production uses the `api/` routes and Supabase.

## Architecture

- `scripts/import_data.py` streams the CSV with Python's `csv.DictReader`, validates the exact header, normalizes codes, pincodes, and dates, then inserts rows in batches.
- `data/enterprise.db` is a local SQLite database generated by the importer.
- `scripts/server.py` serves static files and JSON APIs with server-side pagination, filtering, sorting, metadata, and record detail lookup.
- `public/app.js` keeps the UI responsive with debounced global search, request cancellation, loading skeletons, and page-sized API responses.

## Index Choices

Indexes are created for the fields used by exact filters and common sorts: `state`, `district`, `pincode`, `registration_date`, `lg_st_code`, and `lg_dt_code`. A compound `state, district` index supports the dependent district dropdown. Text search uses SQLite FTS5 across enterprise name, address, and activities when available, with a LIKE fallback.

The importer uses a unique `source_row` so rerunning `npm run import-data` is idempotent while preserving identical rows that appear more than once in the source CSV.
